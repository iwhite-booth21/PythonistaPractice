Question: If you want to create multiple axis level plots which share the same x axis, how would you parameterize your call to plt.subplots()?
Instruction: Choose the option that best answers the question. 

A.Answer A.
Using the “universal_x” input argument to the plt.subplots() function

B.Answer B.
Using the “share_x” input argument to the plt.subplots() function

C.Answer C.
Using the “unix” input argument to the plt.subplots() function

D.Answer D.
Using the “sharex” input argument to the plt.subplots() function

✅ D. Using the sharex input argument to the plt.subplots() function

Explanation:

plt.subplots() can create multiple axes (subplots) in one figure.
To make all subplots share the same x-axis, you use the sharex parameter:

    fig, axes = plt.subplots(nrows=3, ncols=1, sharex=True)

This ensures that zooming, limits, and ticks on the x-axis are shared across all subplots.

Question: What does the error band of a line convey by default in Seaborn?
Instruction: Choose the option that best answers the question. 

A.Answer A.
The error bands convey the 95th percentile of the confidence interval in that category

B.Answer B.
The error bands convey whether there are null values in the data in that category

C.Answer C.
The error bands convey whether there are duplicates in the data in that category

D.Answer D.
The error bands convey whether there are outliers in the data in that category

✅ A. The error bands convey the 95th percentile of the confidence interval in that category

Explanation:
In Seaborn, functions like sns.lineplot() or sns.lmplot() show shaded error bands around the line by default.
These bands represent the 95% confidence interval of the estimate at each point, giving a visual sense of uncertainty in the line.
They do not indicate nulls, duplicates, or outliers—only the confidence interval.

Question: What is the difference between a strip plot and a swarm plot?
Instruction: Choose the option that best answers the question. 

A.Answer A.
The X and Y axes of a swarm plot are always continuous, while a strip plot always has a categorical X axis and a continuous Y axis

B.Answer B.
The swarm plot creates individual graphs for every category on the X axis, while the strip plot creates a single graph

C.Answer C.
The swarm plot visualizes univariate data using data bars, while the strip plot visualizes data using points

D.Answer D.
The swarm plot applies noise called jitter to the chart so that the no data points overlap, while a strip plot allows overlapping data

✅ D. The swarm plot applies noise called jitter to the chart so that no data points overlap, while a strip plot allows overlapping data

Explanation:
Both strip plots and swarm plots are used to visualize categorical vs. continuous data.
Strip plot: places points along a categorical axis, but points can overlap if many have the same value.
Swarm plot: automatically adjusts points so that they don’t overlap, creating a “beeswarm” effect.
    sns.stripplot(x='Category', y='Value', data=df)   # points may overlap
    sns.swarmplot(x='Category', y='Value', data=df)   # points don’t overlap
